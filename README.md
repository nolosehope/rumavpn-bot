# РумаВПН — Telegram-бот продажи VPN

Бот с кнопочным меню: клиент выбирает тариф и количество устройств, переводит
деньги по реквизитам, жмёт «Я оплатил» — заявка улетает в админ-чат, админ
выдаёт VPN-ключ прямо через бота, клиент получает ключ + инструкцию + просьбу
об отзыве.

## Как работает

```
Клиент                              Бот                        Админ-чат
───────                             ─────                      ─────────
/start  ──────────────► меню: Купить / Мои ключи / Поддержка
«Купить VPN» ─────────► выбор тарифа → выбор устройств
                      ► экран оплаты: реквизиты, сумма, № заказа
переводит деньги
жмёт «Я оплатил» ────► «Заявка отправлена, админ свяжется с вами» ──► 🆕 карточка заявки:
                                                                       юзер, тариф, устройств, сумма
                                                                       [✅ Выдать ключ][⚡ Авто][❌ Отклонить]
                      ◄─────────────────────────────────────────────  админ проверил оплату
ключ + инструкция ◄───  «Доступ выдан!» + «Спасибо за заказ,          + подтверждение
«❤️ Оставить отзыв»      оставьте отзыв ❤️»
```

Два способа выдачи ключа:
- **✅ Выдать ключ** — админ присылает ключ текстом в чат, бот доставит его клиенту.
- **⚡ Авто** — бот сам берёт первый ключ из файла `keys.txt` (по одному в строке)
  и отправляет клиенту. Удобно, если заранее наготовить пул ключей.

## Установка и запуск

1. **Установите Python 3.12+** (галочка *Add python.exe to PATH* при установке).

2. **Установите зависимости** (в папке проекта):
   ```
   pip install -r requirements.txt
   ```

3. **Создайте бота**: в Telegram откройте [@BotFather](https://t.me/BotFather)
   → `/newbot` → имя `РумаВПН`, username вида `rumavpn_bot`. Сохраните токен.

4. **Узнайте ID админ-чата**:
   - *Личный чат (проще всего):* напишите вашему боту `/id` — он ответит ID чата.
   - *Группа админов:* создайте группу, добавьте туда бота, в BotFather
     выполните `/setprivacy` → выберите бота → **Disable** (иначе бот не увидит
     ключи, которые вы присылаете), затем напишите в группе `/id`.
   - Можно дополнительно узнать свой ID через [@userinfobot](https://t.me/userinfobot).

5. **Создайте файл `.env`**: скопируйте `.env.example` под именем `.env` и заполните:
   - `BOT_TOKEN` — токен от BotFather;
   - `ADMIN_CHAT_ID` — ID из шага 4;
   - `PAYMENT_REQUISITES` — ваши реквизиты (перенос строки — `\n`);
   - `REVIEW_URL`, `SUPPORT_URL` — ссылки на канал отзывов и поддержку.

6. **Запустите бота**:
   ```
   python bot.py
   ```

## Что где менять

| Что | Где |
|---|---|
| Токен, ID админ-чата, реквизиты, ссылки | `.env` |
| Название сервиса | `config.py` → `SERVICE_NAME` |
| Тарифы и цены | `config.py` → `TARIFFS` |
| Количество устройств и доплаты | `config.py` → `DEVICE_OPTIONS` |
| Инструкция «куда вводить ключ» | `config.py` → `INSTRUCTION` |
| Все тексты сообщений | `texts.py` |
| Пул ключей для автовыдачи | `keys.txt` (по одному ключу в строке) |

Заявки, статусы и выданные ключи хранятся в базе `bot.db` (SQLite) —
кнопка «🔑 Мои ключи» показывает клиенту его ключи.

## Мини-приложение (магазин)

`webapp/index.html` — витрина в 3 шага: тариф → устройства → оформление.
Кнопка «Оформить заказ» закрывает приложение, и бот присылает в чат реквизиты
с кнопкой «Я оплатил» — дальше обычная заявка админу.

Чтобы включить:

1. Разместите файл `webapp/index.html` на любом HTTPS-хостинге. Бесплатно за
   5 минут — [GitHub Pages](https://pages.github.com/): создайте репозиторий,
   положите файл, включите Pages — получите адрес вида
   `https://ВАШ_ЛОГИН.github.io/имя-репо/`. Подойдут и Netlify / Vercel
   (перетаскивание папки в браузере).
2. Впишите адрес в `.env`:
   ```
   WEBAPP_URL=https://ВАШ_ЛОГИН.github.io/имя-репо/
   ```
3. Перезапустите бота — в меню появится кнопка «🛍 Магазин», а слева от поля
   ввода — синяя кнопка меню.

Важно: цены в `webapp/index.html` (блок `TARIFFS` и `DEVICES` в начале
скрипта) должны совпадать с ценами в `config.py` бота — поменяли цену,
поменяйте в обоих местах.

## Работа 24/7

Бот работает, пока запущен `python bot.py`. Для круглосуточной работы
перенесите его на VPS/хостинг и держите процесс живым, например через
`screen`, `systemd` или панель хостинга (бечлокация: дешевле VPS за 150–200 ₽/мес).
