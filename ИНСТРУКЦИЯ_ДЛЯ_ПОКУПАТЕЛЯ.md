# 📦 Инструкция для покупателя бота «РумаВПН»

Поздравляем с покупкой! Этот документ — пошаговая инструкция, как запустить
бота и мини-приложение (магазин) на себя. Займёт 20–30 минут.

**Важно понимать из чего состоит система:**

| Часть | Что это | Где живёт |
|---|---|---|
| Бот | сама программа продаж в Telegram | любой компьютер/сервер с Python |
| Мини-приложение | веб-магазин (витрина тарифов) | бесплатный хостинг GitHub Pages |
| База bot.db | заявки и выданные ключи | создаётся сама рядом с ботом |

---

## Шаг 1. Создайте СВОЕГО бота в Telegram

Бота нельзя «передать» с одного аккаунта на другой, поэтому вы создаёте
своего — это займёт 2 минуты:

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) → кнопка **START**.
2. Отправьте команду `/newbot`.
3. Введите имя бота (например, `РумаВПН`) — его будут видеть клиенты.
4. Введите username — должен оканчиваться на `bot`, например `rumavpn_shop_bot`.
5. BotFather пришлёт **токен** вида `7712345678:AAE...` — скопируйте его.
   🔒 Никому не показывайте токен — это полный доступ к боту.

## Шаг 2. Установите Python на компьютер

1. Скачайте Python с https://www.python.org/downloads/ (кнопка Download Python 3.12+).
2. Запустите установщик и **обязательно поставьте галочку
   «Add python.exe to PATH»** (в самом низу первого экрана) → Install Now.
3. После установки откройте командную строку (Пуск → введите `cmd`) и проверьте:
   ```
   python --version
   ```
   Должно показать версию, например `Python 3.12.10`.

## Шаг 3. Получите файлы бота

Скачайте проект: на странице репозитория нажмите зелёную кнопку **Code →
Download ZIP**, распакуйте в любую папку, например `C:\rumavpn`.

Либо, если вам передали доступ к репозиторию, склонируйте его:
```
git clone https://github.com/АВТОР/rumavpn-bot.git
```

## Шаг 4. Установите зависимости

В командной строке перейдите в папку проекта и выполните:
```
cd C:\rumavpn
pip install -r requirements.txt
```

## Шаг 5. Настройте файл .env

1. В папке проекта откройте файл `.env.example` Блокнотом.
2. Сохраните его копию под именем `.env` (именно так, без расширения).
3. Заполните строки:

```
BOT_TOKEN=токен_из_шага_1

# Пока оставьте пустым — заполните на шаге 7
ADMIN_CHAT_ID=

# ВАШИ реквизиты для оплаты (клиент их увидит перед оплатой)
# перенос строки обозначается \n
PAYMENT_REQUISITES=💳 Карта: 2200 xxxx xxxx xxxx\n🏦 Банк: Т-Банк\n👥 Получатель: Иван И.

# Ваши ссылки: канал с отзывами и ваша личка для поддержки
REVIEW_URL=https://t.me/ваш_канал
SUPPORT_URL=https://t.me/ваш_юзернейм

# Заполните на шаге 8 (мини-приложение)
WEBAPP_URL=

# Прокси НЕ нужен, если Telegram у вас работает и так — оставьте пустым.
# Если Telegram заблокирован провайдером и вы пользуетесь v2rayN/VPN:
# укажите socks5://127.0.0.1:10808 (порт вашего прокси-клиента)
PROXY_URL=
```

## Шаг 6. Первый запуск

Запустите файл **`start.bat`** (двойной клик). Должно открыться окно с
надписью «Бот запущен». Окно должно оставаться открытым, пока бот работает —
закрыли окно, бот выключился.

Проверьте в Telegram: найдите своего бота, нажмите **START** — должно
прийти приветственное меню с кнопками.

## Шаг 7. Подключите админ-чат (куда падают заявки)

1. Напишите своему боту команду `/id` — он ответит числом, например `123456789`.
2. Вставьте это число в `.env` в строку `ADMIN_CHAT_ID=123456789`.
3. Перезапустите бота (закройте чёрное окно, откройте `start.bat` снова).

*Хотите, чтобы заявки падали в группу с напарником? Создайте группу,
добавьте туда бота, в BotFather выполните `/setprivacy` → выберите бота →
**Disable**, затем напишите в группе `/id` и вставьте этот ID.*

## Шаг 8. Подключите мини-приложение (магазин)

Магазин — это веб-страница, Telegram требует, чтобы она лежала на
интернет-адресе с HTTPS. Бесплатно это делается через GitHub Pages:

1. Зарегистрируйтесь на https://github.com (если аккаунта нет).
2. Откройте репозиторий с ботом, который вам передали, и нажмите
   **Fork** (создаст вашу копию).
3. В вашей копии: **Settings → Pages → Source: Deploy from a branch →
   ветка `main`, папка `/ (root)` → Save**.
4. Через 1–2 минуты магазин будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/rumavpn-bot/webapp/`
   (проверьте в браузере — должна открыться витрина тарифов).
5. Впишите этот адрес в `.env`:
   ```
   WEBAPP_URL=https://ВАШ_ЛОГИН.github.io/rumavpn-bot/webapp/
   ```
6. Перезапустите бота. В меню появится кнопка **🛍 Магазин** и синяя кнопка
   слева от поля ввода.

## Шаг 9. Проверьте, что всё работает (чек-лист)

Напишите боту `/start` и пройдите путь клиента:

- [ ] Меню с кнопками: Купить VPN, Магазин, Мои ключи, Поддержка
- [ ] 🛒 Купить VPN → тариф → устройства → пришли реквизиты и «Я оплатил»
- [ ] Нажали «Я оплатил» → в админ-чат пришла заявка (тариф, юзер, сумма)
- [ ] На заявке нажали «✅ Выдать ключ» → прислали любой текст → клиенту
      пришёл ключ, инструкция и просьба об отзыве
- [ ] «🔑 Мои ключи» показывает выданный ключ
- [ ] 🛍 Магазин открывается, заказ из магазина приходит в чат

## Ключи для автовыдачи ⚡

Чтобы не выдавать ключи руками: создайте в папке бота файл `keys.txt` и
положите туда VPN-ключи — по одному в строке. Кнопка «⚡ Авто» на заявке
будет выдавать их по очереди автоматически.

## ❓ Частые проблемы

| Проблема | Решение |
|---|---|
| Окно бота сразу закрывается | Запустите `start.bat`, прочитайте ошибку в окне. Чаще всего не заполнен `.env` или не установлен Python с галочкой PATH |
| `Token is invalid` | Неправильный токен в `.env` — скопируйте заново из BotFather |
| Бот молчит, в окне ошибки про соединение | Провайдер блокирует Telegram. Включите v2rayN/VPN и впишите `PROXY_URL=socks5://127.0.0.1:10808` в `.env` |
| Нет кнопки «🛍 Магазин» | Заполнен ли `WEBAPP_URL` в `.env`? Перезапустите бота и нажмите `/start` ещё раз |
| Магазин не открывается / 404 | Pages ещё строится (подождите 2–3 мин) или не включён (шаг 8, п. 3) |
| Заявка не приходит админам | Не заполнен `ADMIN_CHAT_ID` (шаг 7) |

## ⚠️ Чтобы бот работал 24/7

Пока бот работает на вашем ПК, клиенты могут покупать только когда компьютер
включён и `start.bat` запущен. Для круглосуточной работы перенесите бота на
VPS (арендованный сервер, от ~150 ₽/мес): там Telegram не заблокирован
(`PROXY_URL` оставить пустым), файлы загружаются, ставятся зависимости
(`pip install -r requirements.txt`) и бот запускается командой
`python bot.py` — хостинг-панели обычно умеют держать процесс включённым.
Мини-приложение при этом уже нигде не размещается — оно живёт на GitHub Pages.

## Меняем цены и тексты

- Цены тарифов: файл `config.py` (секция `TARIFFS`, `DEVICE_OPTIONS`)
  **и** тот же блок в начале скрипта `webapp/index.html` — цены должны
  совпадать в обоих местах. После правки index.html заново залейте его в
  свой форк (в браузере на GitHub: карандаш → вставить → Commit), Pages
  обновится сама за минуту.
- Все тексты сообщений: файл `texts.py`.
- Инструкция клиенту «куда ввести ключ»: `config.py` → `INSTRUCTION`.
